> 🚧 **This project is currently under development** 🚧

An advanced desktop application for managing burger shop operations, being built with Java Swing GUI framework. This project will showcase **custom Linked List data structure implementation** and **MVC (Model-View-Controller) architectural pattern**.

## 🌟 Project Vision

This will be an enhanced version of my [original iHungry Burger Shop](https://github.com/PasinduOG/OOP-Swing-iHungry-BurgerShop) project, implementing industry-standard design patterns and custom data structures to demonstrate advanced software engineering principles.

### Functional Features (Coming Soon)

- 👥 Customer information management

## 🏗️ Planned Architecture

### MVC Pattern

The project will follow the **Model-View-Controller** architectural pattern:

- **Model**: Will handle data logic, custom Linked List implementation, and business entities
- **View**: Will manage the user interface using Java Swing components
- **Controller**: Will coordinate between Model and View, handling user interactions

## 📊 Planned Data Structure Implementation

### Why Linked List?
- **Dynamic Memory Allocation**: Efficient memory usage
- **Easy Insertion/Deletion**: O(1) for head operations
- **No Size Limitations**: Grows as needed
- **Real-world Application**: Perfect for order queue management
